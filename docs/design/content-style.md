# Content style

- Sentence case everywhere. Plain verbs on buttons: "Begin mission", "Save version", "Retry step".
- Mythic vocabulary only for nouns that the vocabulary defines (constellation, star, formation).
  Never for actions.
- Agents are named by proper name followed by archetype on first mention in a view: "Iris (Seer)".
- Say what happened, what it affected, and what the person can do. Name external effects
  explicitly: "Nothing outside this workspace was changed."
- No fake success. If something isn't connected, say so ("Web search is not connected").
- Never imply that review guarantees correctness: "Review notes help you check the work. They do
  not guarantee it is correct."
- No exclamation marks, no performative agent chatter, no "I'm thinking…" filler events.
- Times are shown in the viewer's local time, as HH:MM, with the date when it isn't today.
